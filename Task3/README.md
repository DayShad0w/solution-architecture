# Задание 3. Целевая облачная архитектура кассы


Сети нужно убрать сервер из магазина и открывать точку за пять дней, а не за две недели. Касса при этом должна печатать фискальный чек за наличные без интернета и работать с терминалами разных банков.

Схема, найденная на вики, для этого не годится как есть. Ниже она проверена по регламенту и тикетам и нарисована заново.

## Что меняется

В магазине остаётся планшет с браузерной кассой и небольшой Edge Agent. Это не сервер и не база сети. Edge Agent — единственный, кто общается с ККТ и банковским терминалом. Кассовое приложение про USB не знает.

Облако принимает чеки, отдаёт каталог и цены, досылает фискальные документы и списывает остатки. SAP, Promo Engine и Smart Fulfillment остаются в штаб-квартире: касса их вызывает.

Протокол нового терминала, включая Сбербанк ARCUS-2 из тикета INC-8415, закрывается адаптером в HAL. Кассу из-за этого не пересобирают.
