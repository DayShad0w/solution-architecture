# AS-IS. Что неверно на схеме с вики

Артефакт 1 нарисован как C4 Container, но три связи на нём противоречат регламенту и тикетам. Для целевой архитектуры взята исправленная схема [as-is-c4.png](as-is-c4.png)

| Что нарисовано на вики                                                              | Что говорят остальные артефакты                                                                                             |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Касса ходит в SAP по REST в реальном времени и сразу обновляет остатки и лояльность | Регламент, шаг 7.1: SAP в 02:00 формирует XML и по FTP рассылает прайс на локальные базы. Живого REST нет                   |
| Контур штаб-квартиры подписан как HQ Cloud                                          | SAP в кейсе — on-premise. Облаком он не является                                                                            |
| Платёжный терминал один, Ingenico по USB                                            | INC-8415: в купленной сети стоят терминалы Сбербанка с протоколом ARCUS-2, драйвера нет, оценка доработки — три недели      |
| Лояльность выглядит доступной вместе с кассой                                       | INC-8402: без интернета лояльность падает по таймауту, магазин вешает объявление «только наличные»                          |
| База подписана как SQL Express                                                      | В описании компании — платные лицензии Windows Server и SQL. Для TCO взята платная редакция, противоречие вынесено в расчёт |

Остальное на вики сходится с кейсом. Касса — монолит на Windows с драйверами внутри. База стоит на машине в подсобке, касса читает из неё цены и пишет чеки. ККТ подключена по COM. Диск этой машины — единая точка отказа: INC-8433, магазин стоит, пока везут новый системный блок.

Именно эта связка не даёт сделать кассу тонким клиентом «как нарисовано». Браузер не откроет COM и USB, а ночной файл не заменяет справочник, который должен переживать обрыв связи.
